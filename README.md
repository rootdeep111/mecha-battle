# 像素机甲对决 (Pixel Mecha Battle)

一款像素风格的对战机甲游戏，支持单机 AI 对战和多人本地对战，可在电脑和手机上运行。

## 在线游玩

直接访问：[https://rootdeep111.github.io/mecha-battle/pixel-mecha-battle.html](https://rootdeep111.github.io/mecha-battle/pixel-mecha-battle.html)

## 游戏模式

| 模式 | 说明 | 平台 |
|------|------|------|
| 单机模式 (PVE) | 玩家 vs AI Bot，Bot 自动选武器 | 电脑 / 手机 |
| 多人模式 (PVP) | 玩家1 vs 玩家2，同一台电脑本地对战 | 仅电脑 |

> 手机端仅支持单机模式（vs AI Bot），进入游戏后自动选择单机模式。

## 武器系统

开战前可选择武器，三种武器属性各异：

| 武器 | 移速 | 攻击范围 | 连击伤害(1/2/3段) | 防御 | 特点 |
|------|------|----------|-------------------|------|------|
| 短刀 | 5 | 30 | 10/20/30 | 10 | 攻速快，移速快 |
| 长枪 | 3.5 | 60 | 7/15/25 | 10 | 攻击范围大 |
| 剑盾 | 3 | 45 | 10/20/30 | 20 | 防御力最强 |

### 移动端 (触屏)

**需横屏使用**，竖屏时会提示旋转手机。屏幕分为左右两个操作区域：

**左侧 - 移动控制（左拇指）**

| 按钮 | 功能 |
|------|------|
| ← | 向左移动 |
| → | 向右移动 |
| 跳 | 跳跃 |

**右侧 - 战斗按钮（右拇指）**

| 按钮 | 功能 | 位置 |
|------|------|------|
| 攻击 | 三段连击（最大按钮） | 右下角 |
| 防 | 防御/弹反 | 攻击左侧 |
| 远 | 远程攻击 | 防御上方 |
| 喷 | 喷气飞行（长按） | 攻击上方 |

**右侧上 - 技能按钮**

| 按钮 | 功能 | 位置 |
|------|------|------|
| 闪 | 闪现（无消耗） | 防御左侧 |
| 禁 | 禁锢（消耗1怒气） | 远程左侧 |
| 激 | 激光束大招（消耗2怒气） | 技能区上方 |

**菜单操作**
- 模式选择：点击屏幕自动进入单机模式
- 武器选择：点击 ◀ / ▶ 按钮切换武器，点击「开始战斗」按钮进入游戏
- 游戏结束：点击屏幕返回菜单

## 游戏机制

### 连击系统
攻击命中后 20 帧内再次按下可取消后摇进入下一段（平砍 → 横斩 → 下劈），第三段附带击倒效果。

### 完美格挡(弹反)
防御按下后前 5 帧为完美格挡窗口，受击则伤害归零，敌人额外硬直 +10 帧。

### 怒气系统
攻击(+0.05)和受击(+0.1)积攒怒气，上限 2 格。1 格怒气可释放禁锢，2 格怒气可释放激光束大招(150伤害)。

### 闪现
无消耗瞬移 80px，冷却 90 帧，留残影特效。

### 喷气飞行
空中长按喷气键可上升，气泵值满 300 帧(5秒)，地面自动回充。

### 场景元素
- **悬浮平台**：6 个，可踩踏，分布在整个地图
- **木桶**：3 次击打后爆炸造成范围伤害，爆炸后随机重生（地面或平台上）

### 分屏相机
两个角色距离过远时自动切换为分屏模式，各跟随一名角色；靠近后恢复合屏。

## 技术特性

- 纯 HTML5 Canvas + JavaScript，无外部依赖

- 触屏虚拟按键，支持多点触控

## 本地运行

### 方式一：直接打开
双击 `pixel-mecha-battle.html` 即可在浏览器中游玩（桌面端完整功能）。

### 方式二：本地服务器（推荐，支持 PWA 安装）
```bash
python -m http.server 8888
```
然后浏览器访问 `http://localhost:8888/pixel-mecha-battle.html`，可在浏览器地址栏安装为桌面应用。

## 安装为 APP

1. 用 Chrome/Edge 打开游戏页面
2. 点击地址栏右侧的安装图标，或通过菜单选择"安装应用"
3. 安装后可从桌面直接启动，全屏运行，支持离线
